如何从 Chrome 导出 Cookie？
  1. 在 Chrome 中打开目标平台，使用你自己的账号登录。
  2. 自行在 Chrome 扩展商店选择可信、支持 Netscape cookies.txt 的本地导出扩展。核对开发者、权限与隐私政策；优先仅授权当前站点，不安装来源不明的扩展。
  3. 在目标平台页面导出当前站点 Cookie，格式选择 Netscape cookies.txt，不选择 JSON。
  4. 点击上方“导入 cookies.txt”。如需自动加载后续导出文件，勾选文件监测并始终导出到同一路径。
  5. Cookie 过期时，在 Chrome 重新登录，再重新导出或点击 Chrome“立即同步”。程序不能代为登录或刷新服务端会话。

Cookie 相当于登录凭据。不要发送给他人、上传网站或提交到 Git；扩展有能力读取这些凭据，导出完成后可撤销扩展授权。
